# Program profile — UP Mathematics (गणित) Grades 1–3, AY 2026–27 (draft, unreviewed)

Phase 1 output of [the content architecture plan](../../../docs/CONTENT_ARCHITECTURE_PLAN.md).
Sources: the three archived Teacher Guides (AAText, Kruti-compatible); decoded text in
`extracted/matter/`; [sections.json](sections.json); [pagemap.json](pagemap.json). Pdf pages
(printed = pdf − 2). Unreviewed.

## Shape of each guide (contents page, pdf 7)
Front: cover, NIPUN list with LO codes (p2), title, weekly teacher tracker (p4), credits, guide
usage (p6), contents, annual-weekly objectives (G1 8–10, G2/G3 8–11), weekly overview (G1 11–14,
G2/G3 12–15), NIPUN foundations (G1 15–16, G2/G3 16–17). Lessons in unit blocks with unit-opener
pages. Back: teaching process (assessment, periodic revision, ELPS, GRR, math blocks), materials
(kit, posters, board; G2 multigrade p123; G3 picture-story book p117 and week-21 samples),
procedural-fluency sample questions per week, weekly assessment tracker.

## Ontology found
- **Outcomes.** 14 NIPUN LOs per grade with codes: G1 M101.1–M106.3, G2 M201.1–M207.2,
  G3 M301.1–M308.2 (sub-codes = sub-LOs). Split into weekly teaching objectives, 3 per week:
  G1 45; G2 12 (Class 1 review) + 57; G3 12 (Class 2 review) + 57.
- **Scope and sequence (annual-weekly objectives).** Table: week → NIPUN code(s) → objective →
  TG pages → workbook pages. This is the stated LO → week → page link the model needs.
- **Weekly cycle (weekly overview).** Three phases: अनुदेशात्मक कार्य (शिक्षण योजना 1–3, गणित खेल,
  अभ्यास), समेकन और आकलन (‘मैंने सीख लिया’, समेकन शिक्षण योजना, खोजें और जानें), रिमीडियल और
  पुनरावृत्ति (साप्ताहिक पुनरावृत्ति, रिमीडियल शिक्षण योजना). Day 4 period 3 left open; procedural
  fluency daily; teachers write 8–10 questions on days 1, 2, 3, 5, 6.
- **Periodic revision.** Weeks 13 and 20.
- **Teaching process.** ELPS (Experience, Language, Pictures, Symbols) and GRR (मैं करूँ आप देखो …).
- **Materials.** Math kit, posters, board, self-made material, (G3) picture-story book.

## Workbooks (आनंदमय गणित G1–G2, गणित मेला G3)
Front: cover, NCERT math-kit list (G1/G2 p2), title, credits, tick-mark instructions and periodic
revision (p5), worksheet legend कार्यपत्रक अवलोकन (top strip = week and worksheet type-number;
bottom strip for the teacher: icon, date, signature; p6, G3 p2), contents by week (p7). Back: the
NIPUN list with LO codes (pdf 111 / 135 / 135). The worksheet type-number on each top strip is a
stated link from worksheet to plan type (अभ्यास, प्रक्रियात्मक प्रवाह, मैंने सीख लिया).
