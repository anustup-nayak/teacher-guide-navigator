# MVP acceptance checklist

Historical baseline/checklist: use [PRD](PRD.md), [architecture](ARCHITECTURE.md)
and the current task evidence for present behavior. Earlier dropdown/separate-screen
flows and test counts below are retained as dated records, not instructions to restore them.

## Functional definition

The teacher finds an actual source lesson through the topic or week/day route, prepares materials, and follows the source teaching phases on a phone. Both routes resolve the same lesson record. Source templates, uncertain text and missing metadata remain explicit.

## Acceptance checks

- [x] Three grades use distinct source records; unavailable schedules do not recycle content.
- [x] Topic, sub-topic, learning outcome code (when stated) and week/day remain connected.
- [x] One browse route is visible at a time, with full-width selected controls.
- [x] Separate Find, Prepare and Teach screens.
- [x] Original GRR phases and other periods retained for direct-teaching plans.
- [x] Weekly source templates distinguished from missing-content defects.
- [x] Nonempty teaching content plus original activity/page image for every plan.
- [x] Saved list, bookmarks, local notes, resume and source-specific persistence keys.
- [x] Previous/next lessons stop at boundaries and stay within grade/subject.
- [x] Hindi interface with English switching and source text preserved.
- [x] Source references and original-page print layout.
- [x] Data validation catches missing steps, duplicate identities/mappings and timing inconsistency.
- [x] Runtime error/unknown lesson and unavailable device storage have fallback states.

## Explicit limits

No cloud sync, user accounts, offline installation or videos are claimed. Hindi subject guides were not supplied in this numeracy source set. Review weeks 13/20 are available through the full source guide, not mapped as invented day plans. Recovered text is not fully manually proofread; original images remain the fidelity reference. Classroom usability and pedagogical effectiveness need actual teacher observation.
